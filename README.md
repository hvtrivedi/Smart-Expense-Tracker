# Smart Expense Analyzer

A Tiny Project for Python/Data Science that analyzes personal transaction data and produces spending insights, visualizations, budget monitoring, and a lightweight forecast.

## Current scope
- CSV transaction input
- Data cleaning and duplicate detection
- Category and payment-method analysis
- Spending trend visualization
- Smart textual insights
- Monthly budget monitoring
- Simple 30-day spending forecast
- Streamlit dashboard

## Future enhancement
Automatic extraction of transaction information from authorized bank/UPI SMS notifications, reducing manual data entry.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
